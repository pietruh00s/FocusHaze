## Added

- **Each display separately.** A new option under **Multiple displays**: every monitor keeps the window you used there most recently bright, instead of one active window for all displays.
- **Delay before dimming.** From *Immediately* up to 5 minutes. After you switch windows, the previous one stays bright for that long and then fades.
- **Dim the taskbar.** Works on every display and with any taskbar position. The taskbar goes back to full brightness while you use it, Start or the tray.

## Fixed

- Opening File Explorer or a Microsoft Store app (such as Calculator) lifted the haze from every display until you clicked another window.

FocusHaze is available on the **[Microsoft Store](https://apps.microsoft.com/detail/9P3J7F0RK3RT)**. It installs in one click and updates automatically, for both x64 and ARM64 PCs.
