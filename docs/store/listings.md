## English (en-US)

**Product name:** FocusHaze

**Short description:** Dim everything except the window you're working in.

**Description:**

FocusHaze helps you concentrate by gently dimming every window except the one you're working in. Background apps and screen clutter fade into a soft haze, so your attention stays on the task at hand.

When you switch windows, the haze follows you instantly and the window you just left fades smoothly into the background. Clicks pass straight through the haze, so you work exactly as before.

FocusHaze runs quietly in the system tray. Turn it on or off with Ctrl+Alt+H, adjust the intensity and color to suit your eyes and screen, and choose whether to dim all displays or only the one you're using.

FocusHaze collects no data, makes no network connections and shows no ads.

**Product features:**
- Dims every window except the active one
- Clicks pass through the haze, so you work as usual
- Adjustable intensity and haze color
- Smooth transitions when switching windows
- Dim all displays or only the active one
- Global shortcut Ctrl+Alt+H
- Optional start with Windows
- Available in 14 languages
- No data collection, no ads

**Search terms:** focus; dim windows; dimmer; concentration; productivity; distraction free; window highlight

**What's new in this version:** First Microsoft Store release.

切换窗口时，遮罩会立即跟随，刚离开的窗口会平滑变暗。点击可以直接穿过遮罩，因此你可以像往常一样工作。

FocusHaze 安静地在系统托盘中运行。使用 Ctrl+Alt+H 开启或关闭，根据你的眼睛和屏幕调整强度和颜色，并选择调暗所有显示器还是只调暗正在使用的那一台。

FocusHaze 不收集任何数据，不进行网络连接，也不显示广告。

**功能:**
- 调暗除活动窗口外的所有窗口
- 点击可穿过遮罩，照常工作
- 可调节强度和遮罩颜色
- 切换窗口时平滑过渡
- 所有显示器或仅活动显示器
- 全局快捷键 Ctrl+Alt+H
- 可选随 Windows 启动
- 支持 14 种语言
- 不收集数据，无广告

**搜索词:** 专注; 调暗窗口; 屏幕变暗; 聚焦; 效率; 免打扰; 窗口高亮

**新增功能:** 首次在 Microsoft Store 发布。
