## Changed

- **A Windows 11 style tray menu.** Right-clicking the notification-area icon now opens a menu that looks like other Windows 11 menus and follows the light or dark theme. The items are the same as before: **Settings…**, **Dimming** (Ctrl+Alt+H) and **Quit**.
- **Lighter in the background.** A few seconds after you close the settings window or the tray menu, FocusHaze gives unused memory back to Windows, so Task Manager shows a few MB instead of 60–100 MB.

FocusHaze is available on the **[Microsoft Store](https://apps.microsoft.com/detail/9P3J7F0RK3RT)**. It installs in one click and updates automatically, for both x64 and ARM64 PCs.
